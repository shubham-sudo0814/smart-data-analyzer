
# Smart Data Analyzer

## Overview

Smart Data Analyzer is a Python-based data analysis project that helps convert rough datasets into clean and structured data.

The program supports both CSV and Excel files and performs:

* Data Cleaning
* Missing Value Handling
* Duplicate Removal
* Revenue Analysis
* Data Visualization

---

## Features

* CSV & Excel File Support
* Missing Value Detection
* Missing Value Cleaning
* Duplicate Row Removal
* Dataset Information
* Revenue Calculation
* Bar Graph Visualization
* Correlation Heatmap
* Export Cleaned Dataset

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* OpenPyXL

---

## Project Workflow

1. User uploads CSV or Excel file
2. Program reads dataset
3. Missing values are detected and cleaned
4. Duplicate rows are removed
5. Revenue analysis is performed
6. Graphs and heatmaps are generated
7. Cleaned dataset is exported

---

## Output Files

* cleaned_sales_data.csv
* revenue_by_product.png
* correlation_heatmap.png

## How To Run

### Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn openpyxl
```

### Run Program

```bash
python main.py
```
